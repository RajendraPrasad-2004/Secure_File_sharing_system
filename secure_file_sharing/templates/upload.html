What happens next

  1. The server checks the file name, type and size.
  2. A new random 256-bit AES key is created for this file.
  3. The file is encrypted with AES-256-GCM, which also adds an integrity tag.
  4. The AES key is encrypted with your RSA public key (OAEP, SHA-256).
  5. Only the ciphertext and the protected key are stored. The original is never saved.
